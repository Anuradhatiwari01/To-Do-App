# To-Do App

A modern and responsive To-Do List Web Application built using **HTML, CSS, and Vanilla JavaScript**.

The application helps users organize daily tasks efficiently with features like task creation, completion tracking, filtering, statistics, and persistent storage using Local Storage.

## Live Demo

🔗 https://anuradhatiwari01.github.io/To-Do-App/

---

## Features

### Task Management

* Add new tasks
* Delete tasks
* Mark tasks as completed
* Prevent empty task creation
* Add tasks using the Enter key

### Task Statistics

* Total tasks count
* Completed tasks count
* Automatic statistics updates

### Task Filtering

* View All tasks
* View Active tasks
* View Completed tasks

### Data Persistence

* Save tasks using Local Storage
* Tasks remain available after page refresh
* Tasks remain available after closing and reopening the browser

### User Experience

* Responsive design
* Clean and modern interface
* Smooth hover effects
* Friendly empty-state messages
* Mobile-friendly layout

## ⚙️ How It Works

1. Users can create tasks.
2. Tasks are stored in an array of objects.
3. Every change is automatically saved to Local Storage.
4. On page load, saved tasks are retrieved and displayed.
5. Filters allow users to view all, active, or completed tasks.
6. Statistics update automatically whenever tasks change.
